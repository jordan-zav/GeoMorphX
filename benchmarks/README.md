# Benchmarks

Performance artifacts are generated by the CLI:

    geomorphx benchmark --out-dir benchmarks/out --size 512 --repeats 3
    geomorphx benchmark-batch --dem-dir data/dems --out-dir benchmarks/batch_out --recursive

From a development checkout, replace geomorphx with python -m cli.geomorphx_cli.
Use the installed entry point when working with a packaged Python environment.

Reports include timings and numerical summaries; plots are optional when the
plotting dependency is available. Generated results are run artifacts, not
published reference datasets or evidence of scientific accuracy.

The benchmark's independent tile microtests do not reproduce production halos
and global normalization. Use the raster/streaming tests for continuity checks;
do not interpret microbenchmark timing as regional performance validation.
See [memory and tiling](../docs/SCALABILITY.md).
