# GeoMorphX RRIM Suite QGIS Plugin

Built from your released QGIS-RRIM structure, then extended to migrate the suite into Processing algorithms.

## Classic RRIM
- RRIM Generator
- RRIM RGB Composer

## GeoMorphX Suite
- GeoMorphX Suite Compute
- GeoMorphX Suite Compute Batch
- GeoMorphX Suite Benchmark
- GeoMorphX Suite Benchmark Batch

## Geomorphometry blocks (paper-backed additions)
- GeoMorphX Geomorphons (Simplified)
- GeoMorphX Curvature Block (profile, plan, mean)
- GeoMorphX TPI + Wetness Proxy

Notes:
- Classic RRIM tools are preserved.
- Suite tools call GeoMorphX Python modules from this repository.
